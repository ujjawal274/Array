🔄 LeetCode #1 — Two Sum

1️⃣ Problem ka Core Logic

Array mein 2 different elements find karne hain jinka sum target ke equal ho. Har element ko uske baad wale elements ke saath check karo; match milte hi un dono ke indexes [i, j] return karo.

i = current element ka index
j = i ke baad wale element ka index

nums[i] + nums[j] == target
        ↓
    [i, j]


2️⃣ Important Concept / Pattern

Nested Loop + Two Indexes

- i → first element ka index
- j → second element ka index
- j = i + 1 → same element ko dobara use nahi karna
- == → comparison (check karna)
- [i, j] → indexes return karna

for i in range(0, len(nums)):
